# 🎨 Design System Builder

A modern **Design System Generator UI** built with pure **HTML, CSS, and JavaScript**.  
It helps developers quickly generate **color palettes** and **spacing scales** for UI design systems.

---

## 🚀 Live Features

✨ Beautiful SaaS-style UI  
🎨 Random Color Palette Generator  
📏 Spacing Scale Generator  
📋 One-click Copy to Clipboard  
🌈 Glassmorphism + Gradient Design  
📱 Fully Responsive Layout  
⚡ No frameworks (Vanilla JS only)
